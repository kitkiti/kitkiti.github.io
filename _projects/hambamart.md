HambaMart is a multi-role livestock marketplace for buyers, sellers, and administrators.

## Highlights

- Designed the complete EER diagram and relational database schema.
- Modeled product, transaction, and inventory workflows.
- Implemented search by category, title, and price range using Django ORM.
- Built a template-driven frontend with role-based access control.

## Technologies

Django, MariaDB/MySQL, HTML, and CSS.
