Mewply is a music-streaming platform built as a three-tier system with separate user, administration, and backend applications.

## Highlights

- Designed REST APIs using an MVC architecture.
- Implemented JWT and Bcrypt authentication.
- Built responsive audio playback and playlist-management flows.
- Integrated Cloudinary for audio and artwork storage and streaming.

## Technologies

MongoDB, Express, React, Node.js, Tailwind CSS, and Cloudinary.
